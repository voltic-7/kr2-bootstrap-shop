## 1. Описание проекта

Проект представляет собой отдельную реализацию многостраничного сайта интернет-магазина футбольной экипировки и инвентаря **FootballShop** исключительно на базе **HTML + Bootstrap 5**.

В соответствии с требованиями методических указаний:
* КР №2 **не является адаптацией КР №1** с ручным написанием CSS. Это независимая реализация той же предметной области (интернет-магазин футбольной экипировки) средствами фреймворка **Bootstrap 5**;
* Оформление и сетка страниц построены строго на стандартных классах и компонентах фреймворка без написания лишнего стороннего кода;
* Файл `css/custom.css` подключён строго после Bootstrap и содержит только точечные стилевые настройки (высоты картинок `object-fit: cover`, эффекты приподнимания карточек при наведении, стили для карусели);
* Вся интерактивность интерфейса (раскрытие мобильного меню, открытие и закрытие модального окна, переключение слайдов карусели, работа аккордеона FAQ, переключение вкладок характеристик) работает **штатно через официальный бандл `bootstrap.bundle.min.js` и стандартные HTML data-атрибуты (`data-bs-*`)** без сторонних JavaScript-скриптов;
* Bootstrap подключён **локально без использования CDN** (размещён в каталоге `vendor/bootstrap/`), что гарантирует автономную работу сайта без внешних сетевых зависимостей.

## 2. Используемый фреймворк и способ подключения

* **Фреймворк:** Twitter Bootstrap v5.3.3.
* **Способ подключения:** **Локальное подключение (без CDN)**.

### Файлы фреймворка в проекте:
* `vendor/bootstrap/css/bootstrap.min.css` — скомпилированная и минифицированная версия стилей Bootstrap;
* `vendor/bootstrap/js/bootstrap.bundle.min.js` — скомпилированный JavaScript-бандл (включает Popper.js для работы выпадающих списков, модальных окон, аккордеона, вкладок и мобильного меню).

### Порядок подключения в HTML:
В теге `<head>`:
```html
<!-- Локальный Bootstrap CSS -->
<link rel="stylesheet" href="vendor/bootstrap/css/bootstrap.min.css">
<!-- Собственный файл стилей подключается строго после Bootstrap -->
<link rel="stylesheet" href="css/custom.css">
```

Перед закрывающим тегом `</body>`:
```html
<!-- Локальный Bootstrap JS Bundle -->
<script src="vendor/bootstrap/js/bootstrap.bundle.min.js"></script>
```

## 4. Реализованные компоненты Bootstrap

В проекте задействован полный спектр базовых и продвинутых компонентов Bootstrap 5:

1. **Сетка (Grid System):**
   * `container` — центрирование и адаптивные границы контента;
   * `row` — создание строк сетки;
   * `col-12`, `col-sm-6`, `col-md-4`, `col-md-6`, `col-lg-3`, `col-lg-4`, `col-lg-5`, `col-lg-6`, `col-lg-7`, `col-lg-8`, `col-lg-9` — гибкая адаптивная раскладка;
   * `g-2`, `g-3`, `g-4`, `g-lg-5` — отступы между колонками и строками (gutters);
   * `align-items-center`, `justify-content-between`, `justify-content-center` — выравнивание flex-элементов.

2. **Навигация (`navbar`):**
   * Фиксированная адаптивная шапка `sticky-top shadow-sm`;
   * Мобильное гамбургер-меню через `navbar-toggler` и `data-bs-toggle="collapse"`;
   * Выпадающий список категорий через `dropdown` и `data-bs-toggle="dropdown"`;
   * Подсветка текущей активной страницы классом `active` и атрибутом `aria-current="page"`.

3. **Карточки (`card`):**
   * Компонент `card` с классами `card-body`, `card-title`, `card-text`, `card-header`, `card-img-top`;
   * Использование `h-100` и `d-flex flex-column` для идеального выравнивания кнопок в карточках товаров разной высоты;
   * Карточки преимуществ, товаров, отзывов и карточки администраторов.

4. **Кнопки (`btn`):**
   * `btn-primary`, `btn-outline-primary`, `btn-warning`, `btn-secondary`, `btn-outline-secondary`, `btn-outline-light`;
   * Размеры `btn-lg` и `btn-sm`;
   * Кнопка закрытия модальных окон и алертов `btn-close` и `btn-close-white`.

5. **Значки и метки (`badge`):**
   * `badge bg-success` («Новинка»);
   * `badge bg-warning text-dark` («Хит продаж»);
   * `badge bg-danger` («Скидка -15%»);
   * `badge bg-primary`, `badge bg-info text-dark`, `badge bg-secondary`.

6. **Сообщения и уведомления (`alert`):**
   * `alert alert-info` с `role="alert"` — подсказки в каталоге и форме заказа;
   * `alert alert-success` — подтверждение информации о наличии и доставке;
   * `alert alert-warning` — учебное предупреждение о демонстрационных данных;
   * `alert alert-primary` — промо-блок со скидками на главной странице.

7. **Модальное окно (`modal`):**
   * `modal fade` с `modal-dialog-centered`, `modal-header`, `modal-body`, `modal-footer`;
   * Открытие: штатный атрибут Bootstrap `data-bs-toggle="modal" data-bs-target="#orderModal"`;
   * Закрытие: штатный атрибут Bootstrap `data-bs-dismiss="modal"`.

8. **Формы и элементы ввода:**
   * `form-control` — текстовые поля, телефон, дата, e-mail, textarea;
   * `form-select` — выпадающие списки выбора товаров, способов оплаты и сортировки;
   * `input-group` и `input-group-text` — поле телефона с префиксом `+7`, фильтры цен с префиксами «От» и «До»;
   * `form-check`, `form-check-input`, `form-check-label` — чекбоксы согласия на обработку данных и фильтров каталога;
   * `form-check form-switch` — переключатель «Только в наличии»;
   * `form-label` — доступные подписи полей.

9. **Дополнительные компоненты (Самостоятельная доработка на максимальный балл):**
   * **Аккордеон (`accordion`):** Интерактивный блок «Часто задаваемые вопросы» (FAQ) на главной странице (`#faqAccordion`, `accordion-item`, `accordion-header`, `accordion-button`, `accordion-collapse`, `collapse show`);
   * **Карусель (`carousel`):** Полноразмерный слайдер акций и баннеров на главной странице (`#heroCarousel`, `carousel-fade`, индикаторы, элементы управления prev/next, автопрокрутка `data-bs-ride="carousel"`);
   * **Вкладки (`nav-tabs` / `tab-content`):** Интерактивные табы в карточке товара на `product.html` («Характеристики», «Подробное описание», «Доставка и оплата», «Отзывы»);
   * **Таблица (`table`):** Адаптивная таблица характеристик `table table-striped table-hover table-bordered align-middle table-responsive`;
   * **Хлебные крошки (`breadcrumb`):** Навигационные цепочки на страницах `catalog.html`, `product.html`, `order.html`, `contacts.html`;
   * **Пагинация (`pagination`):** Номера страниц `pagination justify-content-center` в каталоге;
   * **Выпадающие списки (`dropdown`):** Интерактивное меню категорий товаров в шапке.

## 7. Ответы на контрольные вопросы к защите КР №2

1. **Что такое CSS-фреймворк?**  
   Это библиотека заранее написанных и протестированных CSS-классов, готовых UI-компонентов и JavaScript-плагинов, предназначенная для ускорения верстки, обеспечения единого визуального стиля и стандартизации адаптивного поведения интерфейса.

2. **Почему Bootstrap выбран как основной вариант?**  
   Bootstrap является самым популярным, стабильным и всесторонне документированным CSS-фреймворком. Он содержит мощную 12-колоночную сетку на Flexbox, готовую библиотеку доступных компонентов и богатый набор utility-классов.

3. **Какие альтернативные CSS-фреймворки допускаются?**  
   Tailwind CSS (utility-first подход) и Bulma (чистый Flexbox-фреймворк без JavaScript).

4. **Для чего используется `container`?**  
   Класс `container` задает центрированный блок с адаптивной максимальной шириной в зависимости от текущего брейкпоинта экрана и внутренними боковыми отступами (padding), предотвращая прилипание контента к краям окна.

5. **Для чего используется `row`?**  
   Класс `row` создает строку 12-колоночной сетки на Flexbox с отрицательными внешними отступами (margin), компенсирующими padding колонок, и служит непосредственным родителем для элементов `col-*`.

6. **Для чего используются `col-*`?**  
   Классы колонок определяют долю ширины, которую блок занимает в 12-колоночной строке (например, `col-12` — вся ширина, `col-md-6` — половина ширины на средних экранах, `col-lg-4` — треть ширины на больших экранах).

7. **Что такое 12-колоночная сетка Bootstrap?**  
   Это система разметки, в которой ширина строки условно разделена на 12 равных долей. Любые блоки верстаются комбинацией колонок, суммарная ширина которых в одной строке обычно равна 12 (например, 8+4, 4+4+4, 6+6, 3+3+3+3).

8. **Для чего используются `g-*`, `gx-*`, `gy-*`?**  
   Для управления промежутками (gutters) между колонками сетки: `g-*` задает одновременно горизонтальные и вертикальные отступы, `gx-*` — только горизонтальные, `gy-*` — только вертикальные (шкала от 0 до 5).

9. **Для чего используется `navbar`?**  
   Для создания адаптивной навигационной панели сайта с поддержкой брендинга, ссылок, выпадающих списков и мобильного гамбургер-меню.

10. **Почему для мобильного меню нужен Bootstrap JS Bundle?**  
    Потому что раскрытие и скрытие навигационного блока (`collapse`) при нажатии на кнопку `navbar-toggler` управляется JavaScript-скриптом Bootstrap, динамически переключающим классы и высоту контейнера.

11. **Для чего используется `card`?**  
    Для создания универсального гибкого контейнера с рамкой, фоном и отступами, внутри которого размещаются изображение (`card-img-top`), тело (`card-body`), заголовок, текст и кнопки действия.

12. **Для чего используется `badge`?**  
    Для компактных меток, счетчиков и статусов товара («Новинка», «Хит», «Скидка»).

13. **Для чего используется `alert`?**  
    Для вывода контекстных информационных сообщений пользователю (успех, предупреждение, ошибка, справка).

14. **Для чего используется `modal`?**  
    Для отображения диалоговых модальных окон поверх основного контента страницы без перехода на другие URL (в нашем проекте — форма быстрой заявки).

15. **Какие атрибуты нужны для открытия модального окна?**  
    `data-bs-toggle="modal"` (указывает действие) и `data-bs-target="#idОкна"` (указывает селектор целевого модального окна).

16. **Для чего используются `form-control`, `form-select`, `input-group`, `form-check`?**  
    * `form-control` — стилизует текстовые поля `input` и `textarea`;  
    * `form-select` — стилизует выпадающие списки `select`;  
    * `input-group` — объединяет поле ввода с текстовыми префиксами/иконками или кнопками;  
    * `form-check` — стилизует чекбоксы и радио-кнопки.

17. **Чем CDN-подключение отличается от локального подключения Bootstrap?**  
    При CDN файлы загружаются с удаленных серверов (требуется постоянный интернет, есть зависимость от стороннего хостинга). При локальном подключении файлы хранятся непосредственно в репозитории проекта (`vendor/bootstrap/`), что гарантирует автономность и отказоустойчивость.

18. **Какие файлы нужны для локального подключения Bootstrap?**  
    `vendor/bootstrap/css/bootstrap.min.css` (стили) и `vendor/bootstrap/js/bootstrap.bundle.min.js` (скрипты вместе с Popper.js).

19. **Почему `custom.css` должен подключаться после Bootstrap?**  
    В силу каскада CSS (`Cascading Style Sheets`) правила, объявленные позже в HTML-документе, имеют приоритет и позволяют переопределять или дополнять свойства фреймворка без использования антипаттерна `!important`.
